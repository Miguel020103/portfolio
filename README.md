## Proyectos

### Moda Urbana
E-commerce de ropa minimalista orientado a moda urbana.

Desarrollé una tienda online completa que permite a los usuarios explorar productos, seleccionar talla y color, agregar artículos al carrito y realizar un proceso de checkout simulado. También incluye autenticación de usuarios y un panel de administración básico.

**Funcionalidades principales:**
- Catálogo de productos con filtros por categoría
- Página de detalle con selección de talla y color
- Carrito de compras persistente
- Cálculo de envío
- Checkout con simulación de pasarela de pagos
- Login / Registro de usuarios
- Panel de administración

**Tecnologías:** Next.js 16, React 19, TypeScript, Tailwind CSS, Auth.js, Context API

**Demo:** [ecomerce-ropa.vercel.app](https://ecomerce-ropa.vercel.app)

### MIRRA — Mis Registros Académicos
Aplicación desarrollada con Flutter para el seguimiento académico de estudiantes universitarios.

Permite gestionar materias, controlar el avance de la carrera, consultar el historial académico y visualizar estadísticas como promedio y créditos aprobados. Incluye malla curricular y un módulo asistente llamado Turing.

**Funcionalidades principales:**
- Gestión de materias (notas, créditos, estado y prerrequisitos)
- Control del semestre actual
- Malla curricular
- Historial académico
- Estadísticas de avance y promedio
- Módulo asistente Turing
- Almacenamiento local

**Tecnologías:** Flutter, Dart, Shared Preferences

**Demo web:** [mirra-demo-two.vercel.app](https://mirra-demo-two.vercel.app)

### MI CAJA — Contabilidad para Conductores de InDrive
Aplicación en desarrollo pensada para conductores de InDrive que necesitan llevar un control claro y eficiente de sus ingresos y gastos diarios.

Permite registrar rápidamente ganancias por viajes y todos los gastos operativos (combustible, mantenimiento, peajes, comidas, etc.), para que el conductor conozca con precisión su ganancia real al final del día o de la semana.

**Funcionalidades principales:**
- Registro rápido de ingresos y gastos
- Control por jornadas / días
- Cálculo de ganancia neta
- Almacenamiento local con Hive
- Interfaz simple y orientada al uso diario en la calle

**Tecnologías:** Flutter, Dart, Hive, Google Fonts

**Demo web:** [mi-caja-demo.vercel.app](https://mi-caja-demo.vercel.app)
